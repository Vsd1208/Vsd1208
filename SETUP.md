# Professional GitHub Profile — Setup

## 1. Create the profile repository

Create a **public** GitHub repository with the exact name:

`Vsd1208`

GitHub will automatically treat it as your profile repository.

## 2. Copy the files

Copy:

- `README.md` → repository root
- `.github/workflows/snake.yml` → `.github/workflows/snake.yml`

Commit and push.

## 3. Update your real links

The README intentionally uses a safe placeholder for LinkedIn because the resume supplied to this build did not contain the actual LinkedIn URL.

Replace:

`https://www.linkedin.com/`

with your real LinkedIn profile.

## 4. Contribution snake

GitHub Actions will generate the contribution snake automatically.

You can also open:

Repository → Actions → Generate Contribution Snake → Run workflow

## 5. Important profile hygiene

Before publishing, make sure your strongest repositories are pinned on GitHub.

Recommended order:

1. Carbon-aware VM Placement
2. Call Ticket
3. AQI Prediction System
4. Your strongest current hackathon / Guidewire work
5. Best Spring Boot backend project
6. Best additional technical project

Keep repository names, READMEs and screenshots consistent with the professional identity of this profile.

## Design philosophy

This profile deliberately avoids:

- excessive animated GIFs
- fake-looking skill meters
- huge walls of badges
- unsupported claims
- random quotes
- unnecessary visitor counters everywhere

The goal is a profile that looks distinctive while still being credible to a recruiter or engineering interviewer.
